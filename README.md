# Letuchka V2

Веб-приложение туристического проекта на Next.js: страницы направлений и туров, авторизация и личный кабинет пользователя.

[Демо](https://letuchka-v2.vercel.app/)

## Возможности

- главная страница с направлениями и карточками туров;
- публичные разделы «О проекте» и контактов;
- разделы регистрации, входа, профиля и администрирования;
- API-маршруты внутри Next.js;
- модули работы с Supabase;
- интерфейс на React и CSS.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Supabase JS, JWT, bcryptjs, React Icons.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для функций, связанных с Supabase и авторизацией, потребуется локальная конфигурация окружения. Значения секретов не добавляйте в репозиторий.

```bash
npm run build
npm run start
```

## Текущие ограничения

Форма консультации на главной странице пока имитирует отправку: данные не передаются менеджеру. Показанные отзывы и показатели на главной странице являются содержимым демо, а не подтверждёнными результатами проекта.

В репозитории есть скрипт `lint`, но его работоспособность и production-сборка в рамках этой проверки не подтверждены.

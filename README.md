# Letuchka V2

Веб-приложение на Next.js для образовательного проекта с публичными разделами, авторизацией и личным кабинетом пользователя.

[Демо](https://letuchka-v2.vercel.app/)

## Возможности

- публичные страницы «О проекте», контактов и туров;
- регистрация и вход пользователей;
- профиль пользователя;
- административный раздел;
- API-маршруты внутри Next.js;
- хранение и работа с данными через Supabase;
- адаптивный интерфейс на React и CSS.

## Стек

- Next.js 16 (App Router) и React 19;
- TypeScript;
- Supabase JS;
- JWT и bcryptjs;
- React Icons;
- ESLint.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для функций, связанных с Supabase, создайте локальный файл окружения и укажите необходимые ключи проекта. Секреты не добавляйте в репозиторий.

## Команды

- `npm run dev` — режим разработки;
- `npm run build` — production-сборка;
- `npm run start` — запуск production-сборки;
- `npm run lint` — проверка кода.
